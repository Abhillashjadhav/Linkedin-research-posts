# Repository working agreement

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing this repository.

The owner's standing instruction is issue-first, atomic delivery:

- One independently reviewable outcome per issue and pull request.
- Open or reuse the matching issue before implementation; split unrelated outcomes.
- Keep each commit coherent, including its necessary tests and documentation.
- Obtain a real review of the final head and record it on the GitHub PR before merge.
- Preserve useful work history and verify attribution; do not manufacture activity.

Use existing authorization without asking again. Follow required checks and branch
protections. These instructions and templates are a working agreement, not an
automated merge gate or permission to change repository protections.
